# postforme-kit — ваш ИИ-агент выкладывает ролики в ваши соцсети

Набор для ИИ-агента: он подключит ваши YouTube, Instagram, TikTok и другие соцсети через сервис [Post for Me](https://www.postforme.dev) и будет публиковать ролики и посты по одной вашей фразе: «выложи этот ролик в Reels и на YouTube Shorts завтра в 10 утра».

## Как начать (1 минута)
Вставьте своему агенту (Claude Code, Codex, Antigravity, Cursor — любому агенту с терминалом):

```
Склонируй репозиторий https://github.com/PavelDumbrao/postforme-kit, прочитай AGENTS.md и выполни всё, что там написано: установи себе скилл postforme-publish и проведи меня до первой публикации.
```

Агент поставит скилл, попросит ключ, даст ссылки для подключения соцсетей и проведёт до первого поста. От вас нужны ключ, сам ролик и «да» перед каждой публикацией.

Нет агента с терминалом или хочется всё в одном сообщении: возьмите подробный промпт из [`PROMPT.md`](PROMPT.md).

## Что умеет
| Задача | Как попросить агента |
|---|---|
| Выложить ролик сразу в несколько соцсетей | «Выложи `video.mp4` в Reels и YouTube Shorts, подпись придумай сам» |
| Запланировать публикацию | «Опубликуй завтра в 10:00 по Москве» |
| Разный текст для разных соцсетей | «В YouTube — заголовок и описание, в Instagram — короткая подпись с хештегами» |
| TikTok черновиком | «Отправь в TikTok черновиком, я сам нажму „Опубликовать“» |
| Обложка ролика | «Обложкой поставь кадр на 3-й секунде» или свою картинку |
| Проверить, что вышло | «Покажи ссылки на опубликованное» |
| Статистика | «Сколько просмотров у последних роликов?» |
| Отменить запланированное | «Удали запланированный пост на пятницу» |

Соцсети: YouTube, Instagram, TikTok (обычный и Business), Facebook, X (Twitter), LinkedIn, Threads, Pinterest, Bluesky.

## Что понадобится
- Аккаунт на [app.postforme.dev](https://app.postforme.dev), тариф от $10 в месяц за 1000 публикаций. Подключать можно сколько угодно соцсетей. Как зарегистрироваться и где взять ключ — по шагам в [`guides/registration.md`](guides/registration.md).
- Python 3.9+. Больше ничего ставить не нужно: скрипт работает на стандартной библиотеке.
- По желанию — официальный MCP-сервер Post for Me для агента, см. [`guides/mcp.md`](guides/mcp.md).

## Как это работает
1. Ваш ролик загружается во временное хранилище Post for Me (живёт 24 часа или до публикации).
2. Агент собирает пост: текст, ролик, куда и когда, настройки для каждой соцсети.
3. Показывает вам, что отправит, и ждёт «да».
4. Отправляет один раз, ждёт ответа соцсетей и даёт ссылки на опубликованное.

## Важно
- Ключ хранится только в `.env`, который не попадает в git. Ключ даёт полный доступ ко всем подключённым соцсетям: никому его не показывайте.
- Публикация — действие необратимое: агент всегда показывает пост и ждёт «да».
- Повторный запуск с тем же именем поста не публикует дубль: скрипт помнит созданные посты в `out/`.
- При подключении соцсети вы увидите название «Post for Me» — это нормально, сервис публикует от своего проверенного приложения.
