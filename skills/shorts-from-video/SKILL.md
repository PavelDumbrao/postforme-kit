# Shorts из своего длинного видео

## Что нужно
- **ffmpeg**: macOS `brew install ffmpeg`, Windows `winget install Gyan.FFmpeg`, Linux `sudo apt install ffmpeg`. Проверка: `ffmpeg -version`.
- **Само видео** на компьютере (mp4/mov, горизонтальное).
- **Текст с таймингами** — один из трёх вариантов:
  1. Видео уже на YouTube (можно «по ссылке») — берём авто-субтитры YouTube, там время каждого слова. Нужен yt-dlp (`pip install yt-dlp` или `brew install yt-dlp`):
     `yt-dlp --skip-download --write-auto-subs --sub-langs ru --sub-format vtt -o subs "https://www.youtube.com/watch?v=ID"` → `subs.ru.vtt`. Субтитры появляются через 10–30 минут после загрузки ролика.
  2. Свои субтитры `.srt` или `.vtt` (из монтажки, из Zoom, из сервиса расшифровки).
  3. JSON распознавания (ElevenLabs, Whisper) со словами и временем.

Все команды — из папки набора. На Windows вместо `python3` может быть `python` или `py`.

## Шаги
1. `python3 scripts/shorts.py words subs.ru.vtt -o words.json`
2. `python3 scripts/shorts.py sentences words.json` → список фраз с временем. Прочитай целиком.
3. Выбери 3–6 моментов по правилам ниже, покажи человеку таблицу: время, длина, первая фраза, заголовок. Жди «да» или правок.
4. Составь `plan.json`:
   ```json
   {"video": "/путь/к/видео.mp4", "words": "words.json", "out_dir": "shorts", "mode": "fit",
    "cta": "Полный урок — по ссылке ниже",
    "clips": [
      {"name": "s1", "start": 295.6, "end": 346.7, "title": "Какую модель выбрать: Opus, Sonnet или Haiku"}
    ]}
   ```
5. `python3 scripts/shorts.py plan plan.json --dry-run` — проверь строку «Речь»: клип начинается с первого слова фразы и кончается выводом.
6. `python3 scripts/shorts.py plan plan.json` → `shorts/s1.mp4` (1080×1920, громкость под соцсети). Около минуты на клип.
7. Проверка: `python3 scripts/shorts.py sheet shorts/s1.mp4 --step 0.5` → картинка с кадрами каждые полсекунды. Посмотри её сам: заголовок читается, ничего не налезает, нет чёрных кадров. Покажи человеку клипы.
8. Публикация — по скиллу `postforme-publish` (после «да», каждому клипу своё имя поста):
   `python3 scripts/pfm.py post short-1 --to youtube,instagram --media shorts/s1.mp4 --caption-file s1.txt --title "…" --placement reels`
   Вертикальный ролик до 3 минут YouTube сам делает Shorts. В тексте — ссылка на полный ролик.
   После выхода в YouTube Studio у Shorts → «Связанное видео» → выбери полный ролик: под Shorts появится кликабельная ссылка.

## Как выбирать моменты
- **30–60 секунд.** Короче — мало просмотра, длиннее — досматривают хуже.
- **Крючок в первые 1–3 секунды.** Клип начинается с сильной фразы: вопрос, частый страх, цифра, прямой совет, ошибка. Не с «привет» и «итак».
- **Одна мысль целиком:** вопрос → ответ, проблема → решение. Понятно без остального видео (нет «как я говорил выше», «вот здесь на экране»).
- **Конец — вывод**, а не полуслово.
- Хорошие места: «частый вопрос», «мой любимый приём», сравнение «A или B», «ошибка новичков», история с цифрой, список из 2–3 пунктов.
- Не брать: вступление «сегодня разберём», прощание и домашнее задание.

## Режимы кадра
- `fit` (по умолчанию) — видео целиком по центру, сверху заголовок, снизу призыв, фон — размытый кадр. Подходит для всего, особенно если в видео уже есть субтитры или слайды.
- `crop` — вертикальный кусок во весь экран (лицо крупно). Для «говорящей головы» без субтитров и слайдов. `"cx": 0.5` — центр кадра, `0.3` — левее, `0.7` — правее.
- Свой шрифт: `"font": "/путь/к/шрифту.ttf"` в плане (нужен TTF или OTF с кириллицей).

## Ритм публикации
- 3–4 Shorts в неделю, в разные дни с длинными роликами, между Shorts не меньше 6–8 часов. Можно сразу запланировать: `--schedule 2026-12-01T18:00:00+03:00`.
- Не выкладывать все клипы в один день: они отнимают внимание друг у друга.
- Музыку не накладывать в монтаже — её лучше выбрать в самом приложении соцсети.
- Если в видео ИИ-аватар или ИИ-голос, похожий на реального человека, — отметка ИИ (`contains_synthetic_media: true` для YouTube, `is_ai_generated: true` для TikTok).
