# Post for Me: публикация в свои соцсети

## Перед первым запуском
1. Ключ: файл `.env` в корне набора со строкой `POST_FOR_ME_API_KEY=pfm_live_...` (как получить — `guides/registration.md`). Никогда не печатать ключ в чат и не коммитить.
2. `python3 scripts/pfm.py check` — бесплатно, покажет подключённые соцсети.
3. Нет нужной соцсети — `python3 scripts/pfm.py connect <платформа>`, дать человеку ссылку, после входа — `accounts`.

Все команды запускать из папки набора (`scripts/pfm.py`). Полная справка: `python3 scripts/pfm.py -h` и `python3 scripts/pfm.py post -h`.

## Правило публикации
- Сначала **всегда** запуск без `--yes`: скрипт покажет, куда, когда, какой файл и текст. Перескажи это человеку и жди «да».
- Потом тот же запуск с `--yes`. Это одна отправка: скрипт не повторяет запрос сам и помнит пост в `out/NAME.json` — повтор с тем же NAME не создаст дубль.
- Ошибка сети или таймаут после `--yes` — **не** запускай с новым NAME. Сначала `python3 scripts/pfm.py posts --limit 5`: пост мог создаться.
- `NAME` — короткое имя латиницей, своё для каждого поста: `reels-2026-12-01`, `promo-kurs-1`.

## Рецепт 1. Один ролик в несколько соцсетей сейчас
```
python3 scripts/pfm.py post reels-1 --to instagram,youtube,tiktok --media video.mp4 \
  --caption-file caption.txt --title "Заголовок для YouTube" --placement reels
```
- `--to` — названия платформ, ID аккаунтов (`spc_...`) или `all`.
- `--title` нужен для YouTube (до 100 символов), подходит и для TikTok.
- `--placement reels` — для Instagram/Facebook видео в Reels (`stories` — в истории, `timeline` — в ленту).
- `caption.txt` — текст поста. Хештеги — в конце текста.
- Потом `python3 scripts/pfm.py wait <post_id>` → ссылки. YouTube отвечает дольше остальных (до 15–20 минут).

## Рецепт 2. По расписанию
`--schedule 2026-12-01T10:00:00+03:00` — время всегда с часовым поясом (`+03:00` — Москва). Уточни у человека пояс, если он не сказал. Проверка: `python3 scripts/pfm.py posts --status scheduled`. Отмена: `delete <post_id>` после «да».

## Рецепт 3. Разный текст и настройки для разных соцсетей
Готовые файлы настроек — `examples/configs/*.json`, подключаются флагом `--config`. Ключи верхнего уровня — платформы: `youtube`, `instagram`, `tiktok`, `tiktok_business`, `facebook`, `x`, `linkedin`, `threads`, `pinterest`, `bluesky`. Внутри можно переопределить `caption` (свой текст для этой соцсети) и платформенные поля:
- **youtube**: `title`, `privacy_status` (`public` | `unlisted` | `private`), `made_for_kids`, `tags` (список), `category_id` (`"22"` — люди и блоги, `"27"` — образование, `"28"` — наука и техника), `contains_synthetic_media` (true, если ролик сделан ИИ), `publish_at` (только при `private`), `localizations` (оставить `{}`).
- **instagram**: `placement` (`reels` | `stories` | `timeline`), `share_to_feed`, `collaborators` (список ников), `trial_reel_type` (`manual` | `performance` — пробный Reels для не-подписчиков).
- **tiktok / tiktok_business**: `title`, `privacy_status` (`public` | `private`), `is_draft` (true — уйдёт в черновики TikTok, человек публикует сам), `allow_comment`, `allow_duet`, `allow_stitch`, `is_ai_generated`, `disclose_your_brand`, `disclose_branded_content`, `auto_add_music`.
- **facebook**: `placement` (`reels` | `stories` | `timeline`).
- **pinterest**: `board_ids` (список), `link` (ссылка с пина).
Флаги `--title`, `--privacy`, `--placement` дописываются поверх файла. Неизвестное поле API вернёт ошибкой — тогда сверься с документацией: https://api.postforme.dev/docs.

## Рецепт 4. Черновик / безопасная проба
- YouTube: `--privacy unlisted` (видно только по ссылке) или `private`.
- TikTok: `--config examples/configs/tiktok-draft.json` — ролик придёт в приложение TikTok во «Входящие/черновики», человек публикует сам.
- Весь пост черновиком в Post for Me: `--draft` (ничего не публикуется, пост можно увидеть в app.postforme.dev).

## Рецепт 5. Обложка
`--cover cover.jpg` (файл или ссылка) или `--cover-ms 3000` (кадр на 3-й секунде). Instagram и TikTok могут игнорировать обложку для некоторых форматов — это нормально.

## Рецепт 6. Карусель / несколько файлов
`--media 1.jpg --media 2.jpg --media 3.jpg` — карусель для Instagram/Facebook/Threads/X (лимит числа файлов у каждой соцсети свой; если не пройдёт — ошибка придёт в результате). Порядок как в команде.

## Рецепт 7. Ссылки и статистика
- `python3 scripts/pfm.py status <post_id>` — статус и ссылки по каждой соцсети.
- `python3 scripts/pfm.py feed <spc_id> --metrics` — последние публикации аккаунта со статистикой (просмотры, лайки, комментарии). `--raw` — все поля.
- Ошибка 500/401 на `feed` чаще всего значит, что доступ к соцсети истёк или её подключали без статистики — переподключить `connect`.

## Текст поста: как писать для каждой соцсети
- **YouTube**: заголовок 40–70 символов, суть и польза, без кликбейта-обмана. Описание: 2–3 предложения + что внутри + ссылки + 3–5 хештегов в конце. Shorts — вертикальный ролик до 3 минут, YouTube сам распознаёт его как Shorts.
- **Instagram Reels**: первая строка — крючок (видна до «ещё»), потом 2–4 коротких абзаца, призыв (сохранить, написать в директ), 3–8 хештегов по теме.
- **TikTok**: 1–2 строки, крючок + 3–5 хештегов. Длинный текст не нужен.
- **X**: до 280 символов (без подписки), ролики длиннее 2:20 могут не пройти.
- **LinkedIn / Threads / Facebook**: живой текст от первого лица, без хештег-стены.
Всегда показывай человеку итоговый текст перед публикацией.

## Требования к роликам (кратко, подробно — guides/platforms.md)
- Вертикальные Reels / Shorts / TikTok: 9:16, 1080×1920, MP4 (H.264 + AAC).
- YouTube длиннее 15 минут — только с подтверждённым телефоном на канале.
- Instagram — только профессиональный аккаунт (Автор или Бизнес).
- Post for Me сам ужимает файл, если он не проходит по требованиям соцсети. Очень большие файлы: добавить в media `skip_processing`, но тогда формат — на вашей ответственности.

## Ошибки и что делать
| Сообщение | Что делать |
|---|---|
| `401 ... Please reconnect the account` | Доступ к соцсети истёк: `connect <платформа>` заново |
| `401` без слова reconnect | Ключ неверный или отозван: новый ключ в app.postforme.dev |
| Ссылка `connect` не открывает вход | Соцсеть не включена в проекте Post for Me — включить в настройках проекта |
| Результат `❌` с текстом ошибки | Прочитай текст: формат ролика, длина, лимит соцсети. Исправь и публикуй под **новым** NAME |
| Нет результата через 20 минут | `status <post_id>` позже; YouTube бывает долгим. Не публикуй повторно |
| `Файл не найден` | Проверь путь, лучше абсолютный |
