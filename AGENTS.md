# Инструкция агенту: набор postforme-kit

Ты помогаешь человеку публиковать его ролики и посты в его соцсети через сервис Post for Me. Человек может не быть программистом: веди за ручку, коротко и по-русски, по одному шагу. Не вываливай всё сразу — один шаг, проверка, следующий.

## Шаг 0. Установи скилл себе
Скопируй папку `skills/postforme-publish` туда, где ты хранишь скиллы, и дальше работай по её `SKILL.md`:
- Claude Code: `~/.claude/skills/postforme-publish/` (глобально) или `.claude/skills/postforme-publish/` в проекте;
- Codex: `~/.agents/skills/postforme-publish/` (или `~/.codex/skills/`);
- Antigravity / Gemini CLI: `~/.gemini/skills/postforme-publish/`;
- Cursor и другие: держи `SKILL.md` открытым как правило проекта.
Скрипт `scripts/pfm.py` лежит в корне набора. Запоминай абсолютный путь к папке набора и запускай скрипт оттуда.

## Шаг 1. Проверь окружение (сам, без вопросов)
- `python3 --version` — нужен 3.9+. Нет Python — поставь (macOS `brew install python`, Windows `winget install Python.Python.3.12`, Linux `sudo apt install python3`).
- На Windows команда может называться `python` или `py` вместо `python3` — используй ту, что работает, во всех командах ниже.

## Шаг 2. Аккаунт и ключ
- Спроси, есть ли аккаунт на app.postforme.dev. Нет — проведи по `guides/registration.md`: регистрация, проект типа **Quickstart**, включить нужные соцсети в проекте, тариф, ключ API.
- Попроси создать файл `.env` в папке набора со строкой `POST_FOR_ME_API_KEY=pfm_live_...` (образец — `.env.example`). Лучше, чтобы человек вставил ключ в файл сам. Если он прислал ключ в чат — запиши его в `.env` и больше нигде не повторяй.
- `python3 scripts/pfm.py check` → «Ключ работает» и список подключённых соцсетей.

## Шаг 3. Подключи соцсети
- Спроси, в какие соцсети человек хочет публиковать.
- Для каждой: `python3 scripts/pfm.py connect <платформа>` (youtube, instagram, tiktok, tiktok_business, facebook, x, linkedin, threads, pinterest, bluesky) → дай ссылку → человек открывает, входит, разрешает доступ.
- Если соцсеть не включена в проекте, ссылка не сработает: попроси включить её в app.postforme.dev (см. `guides/registration.md`).
- Перед подключением проговори требования из `guides/platforms.md`: Instagram — только профессиональный аккаунт (Автор или Бизнес), YouTube — подтверждённый телефон для роликов длиннее 15 минут и т.д.
- `python3 scripts/pfm.py accounts` — проверь, что всё `connected`.

## Шаг 4. Первая публикация за 10 минут
Спроси:
1. Какой ролик или картинку выложить (путь к файлу или ссылка).
2. Куда (какие из подключённых соцсетей).
3. Когда: сейчас, в конкретное время или черновиком.
4. Текст: человек пишет сам или ты предлагаешь по рецепту из `SKILL.md` (заголовок для YouTube, подпись с хештегами для Instagram и TikTok).

Дальше — рецепт из `SKILL.md`: проверка без `--yes` → показать человеку → «да» → `--yes` → `wait` → ссылки на опубликованное.

Для первого раза предложи безопасный вариант: YouTube с доступом «по ссылке» (`--privacy unlisted`) или TikTok черновиком (`--config examples/configs/tiktok-draft.json`). Так человек увидит результат, а подписчики — нет.

## Правила
- **Перед каждой публикацией** покажи, куда, когда, с каким текстом и каким файлом уйдёт пост, и жди явного «да». Без «да» — только запуск без `--yes`.
- Один пост — один запуск с `--yes`. Если ответ сети не пришёл или пришла ошибка, **не отправляй заново** — сначала `python3 scripts/pfm.py posts` и `status`: пост мог создаться. Дубль ролика в соцсети не отменить.
- Ключ не печатай, не коммить `.env`, не вставляй в код и в сообщения.
- Не публикуй чужой контент, чужие лица без согласия, музыку без прав.
- Удаление (`delete`) — только запланированных постов и черновиков, и только после «да». Уже опубликованное удаляется в самой соцсети.
- После публикации покажи ссылки и скажи, что YouTube иногда отвечает до 15–20 минут.
- Каждый раз, когда человек говорит «вот так лучше / так не делай» (стиль подписей, хештеги, время публикации, любимые соцсети), допиши это правилом в свой `SKILL.md` в раздел «Мои правила» — скилл станет его.
